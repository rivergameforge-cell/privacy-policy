1. 나이 선택과 보호 모드

처음 실행할 때 만 12세 이하, 만 13~15세, 만 16세 이상 중 하나를 선택하거나 선택 없이 게임을 계속할 수 있습니다. 생년월일과 정확한 나이는 받지 않습니다. 선택한 구간은 기기에만 저장됩니다.

만 16세 미만이거나 나이를 선택하지 않은 경우 광고 SDK·광고 동의 요청과 온라인 랭킹의 신규 인증·조회·제출을 시작하지 않습니다. 기본 게임, 성장 및 기기 내 기록은 이용할 수 있습니다. 이전 버전의 온라인 기록은 보호 모드로 전환하는 것만으로 삭제되지 않으며, 게임 데이터 초기화 또는 지원 문의로 삭제를 요청할 수 있습니다.

2. 처리하는 정보와 목적

게임 진행과 장비, 음량 설정, 나이 구간과 랭킹 중지 설정은 기기에 저장합니다. 이메일이나 이용자가 입력하는 닉네임은 게임 이용에 필요하지 않습니다.

만 16세 이상 이용자의 온라인 랭킹에는 Supabase의 익명 계정 식별자, 자동 생성된 공개 이름, 서버 런 식별자, 모드, 점수, 회차, 처치 수, 플레이 시간과 제출 시각을 사용합니다. 목적은 기록 비교와 비정상 제출 방지입니다. 이름과 최고 기록은 랭킹에서 다른 이용자에게 표시됩니다. 계정 인증 토큰은 기기에 저장하며 공개하지 않습니다. 익명 식별자도 온라인 기록과 연결될 수 있는 데이터로 취급합니다.

만 16세 이상 이용자에게 Google AdMob으로 광고를 제공할 수 있습니다. 광고를 시작하기 전에 필요한 동의 절차를 진행합니다. 광고 서비스는 IP 기반 대략적인 위치, 기기·광고 식별자, 앱 및 광고 상호작용, 진단 정보를 광고 제공·측정·분석 및 부정 이용 방지에 사용할 수 있습니다. 네트워크 서비스에는 HTTPS를 사용합니다.

4. 보관 및 삭제

설정 → 저장 관리 → 게임 데이터 초기화에서 진행 상황, 장비, 유물, 최고 기록과 본인의 익명 계정·온라인 랭킹·런·제출 기록을 함께 삭제합니다. 나이 구간 등 이용자 보호 설정은 유지합니다. 기기의 앱 데이터 삭제나 앱 제거만으로는 서버 기록을 삭제할 수 없습니다.

온라인 계정이 있는 경우 서버 삭제를 확인한 뒤 기기 데이터를 지웁니다. 온라인 계정을 만든 적이 없는 경우에는 인터넷 없이 초기화할 수 있습니다. 처리 중에는 온라인 서비스를 중지하고, 실패하면 완료로 표시하지 않습니다. 서버 확인 실패 시 기기 진행과 재시도에 필요한 인증 정보를 유지합니다. 기기 정리에 실패하면 다음 실행에서 정리를 재시도합니다. 완료 후 사용자가 ‘처음부터 시작’을 선택하기 전까지 새 게임이나 계정을 자동 생성하지 않습니다.

앱 종료나 응답 유실 후에도 삭제 완료를 확인하기 위해 무작위 확인 키를 기기에 저장하고, 서버에는 계정 식별자를 포함하지 않는 확인 키의 해시만 남깁니다. 초기화와 새 게임 시작이 완료되면 기기의 확인 키를 지웁니다.

앱 외부에서도 계정·데이터 삭제 안내에 따라 이메일로 요청할 수 있습니다. 설정에서 복사한 삭제 요청 확인 코드로 본인의 익명 계정을 확인합니다. 서버에는 코드의 해시와 계정 연결만 저장하며 계정 삭제 시 함께 삭제합니다. 코드는 로그인에 사용할 수 없으며, 공개 이름만으로는 삭제를 승인하지 않습니다. 등록 이메일이 없는 익명 계정이므로 코드나 다른 비공개 확인 자료를 잃으면 소유권을 확인하지 못할 수 있습니다. 앱 재설치 없이도 이메일로 요청하고 안내받을 수 있습니다.

삭제 요청 이메일과 확인 자료는 본인 확인·처리·결과 안내에만 사용합니다. 요청 처리 종료 후 90일 이내에 확인 자료와 요청 사본을 삭제합니다. 법적으로 보관이 필요한 경우에는 사유와 기간을 안내합니다. 지원 이메일을 보내면 이메일 주소와 요청 내용이 Google의 이메일 서비스를 통해 처리됩니다.

서버 기록은 삭제 요청 처리 또는 서비스 종료 시까지 보관할 수 있습니다. 런의 유효기간이 지나면 제출할 수 없으며 유효기간 만료가 모든 기록의 즉시 삭제를 뜻하지는 않습니다. 서비스 제공자의 로그 및 백업은 각 제공자의 보관·삭제 절차를 따릅니다.

English

Effective October 2, 2026. This policy describes the protected mode and unified reset in the upcoming launch version 1.0.0. V8REDLINE provides Unlimit Boss Run (com.v8redline.unlimitbossrun). Contact: v8redline.studio@gmail.com.

The app asks for a coarse age band, stored only on the device; it does not ask for a birthday. Users under 16 or with no age selection can play locally without starting ad SDK/consent requests or new leaderboard authentication, reads or submissions. Entering protected mode alone does not delete older online records; deletion can be requested through reset game data or customer support.

For users aged 16 or older, Supabase processes an anonymous account ID, generated public alias, run ID, mode, score, cycle, kills, playtime and submission time for leaderboards and abuse prevention. Public aliases and best records are visible to other players. Authentication tokens remain private on the device. AdMob may process approximate location derived from IP addresses, identifiers, interactions and diagnostics for ads, measurement, analytics and fraud prevention. Required consent is requested before ads start. Network services use HTTPS.

Settings → storage management → reset game data deletes local progress, equipment, relics and best records together with the caller's anonymous account and server leaderboard, run and submission records. Age protection settings remain. Existing online accounts require server-confirmed deletion before local cleanup; never-online users can reset offline. Failed remote requests retain local progress and credentials for retry. Incomplete local cleanup can resume after restart. A new game/account is not created until the user explicitly chooses to start afresh. Removing the app alone does not delete server records.

A random local confirmation key and its server-side hash allow deletion confirmation after a lost response. The receipt contains no account identifier. The local key is removed when reset and explicit fresh start complete.

External deletion requests are available on the deletion page. A private deletion verification code copied from Settings verifies the anonymous account. Only its hash and account mapping are stored on the server, and the mapping is removed with the account. The code cannot be used to log in. A public alias alone is insufficient; if the code and other private evidence are lost, ownership may be unverifiable. Email requests do not require reinstalling the app. Request correspondence is processed through Google's email service, used only for verification and handling, and removed within 90 days after closure unless legally required otherwise. Server records may remain until verified deletion or service closure. Provider logs and backups follow provider retention procedures.
