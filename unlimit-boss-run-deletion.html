앱 안에서 요청

  1. 설정을 엽니다.
  2. 저장 관리의 게임 데이터 초기화를 선택합니다.
  3. 삭제 범위를 확인하고 모두 삭제를 선택합니다. 초기화 완료 메시지를 확인합니다.

요청 즉시 온라인 랭킹을 중지합니다. 통신 실패 메시지가 나오면 삭제가 확인되지 않은 상태이므로 연결 후 다시 시도해 주세요. 실패 후 재시도는 기존 계정으로 진행하며 새 계정을 만들지 않습니다.

앱 외부에서 요청

v8redline.studio@gmail.com으로 삭제 요청 보내기

  1. 제목에 ‘또 보스냐! 계정 삭제 요청’, 본문에 익명 계정과 온라인 기록의 삭제 요청을 적어 주세요.
  2. 보관한 삭제 요청 확인 코드가 있으면 함께 보내 주세요. 앱을 사용할 수 있다면 설정 → 저장 관리 → 삭제 요청 확인 코드 복사에서 받을 수 있습니다. 인터넷 연결과 기존 온라인 계정이 필요하며, 이 작업은 새 계정을 만들거나 데이터를 삭제하지 않습니다.
  3. 코드가 없거나 앱을 사용할 수 없어도 이메일로 먼저 요청할 수 있습니다. 공개 랭킹 이름과 앱을 사용할 수 없는 상황을 알려 주시면, 이미 보관한 비공개 서버 런 식별자 등 대체 자료를 안내합니다. 앱 재설치나 새 계정 생성은 요구하지 않습니다.
  4. 저희가 서버의 코드 해시와 본인 계정 연결을 확인한 뒤 삭제하고, 요청 이메일로 결과를 안내합니다.

확인 코드는 본인 계정의 삭제 요청을 확인하는 비공개 자료입니다. 안전한 곳에 따로 보관하고 지원 이메일 외에는 공유하지 마세요. 공개 이름·공개 점수·이메일 수신 가능 여부만으로 소유권을 인정하지 않습니다. 비밀번호, 로그인 인증 토큰, 전체 저장 파일, 신분증은 보내지 마세요. 익명 계정에는 등록 이메일이나 복구 로그인이 없어서 코드와 다른 비공개 자료를 모두 잃은 경우 본인 확인이 불가능할 수 있습니다. 이 경우 이유와 확인 가능한 대안을 안내하며 다른 사람의 계정은 삭제하지 않습니다.

삭제되는 정보와 유지되는 정보

앱의 초기화는 본인의 익명 인증 계정과 서버 랭킹·런·제출 기록을 확인하여 삭제한 뒤, 기기의 진행 상황·장비·유물·최고 기록과 인증 정보를 지웁니다. 나이 구간 등 이용자 보호 설정은 유지합니다. 완료 후 ‘처음부터 시작’을 선택해야 새 게임이 시작됩니다. 온라인 계정을 만든 적이 없다면 인터넷 없이 초기화할 수 있습니다. 이메일 요청은 서버의 본인 데이터를 삭제하며, 기기 데이터는 앱 또는 기기 설정에서 따로 지워 주세요.

이메일 요청에는 원칙적으로 7일 이내에 확인 절차를 안내하고, 본인 확인을 완료한 뒤 30일 이내에 처리 결과를 알려 드립니다. 지연되거나 법적 보관이 필요한 경우 이유와 예상 기간을 안내합니다. 확인 코드의 서버 연결은 계정과 함께 삭제하며, 요청 이메일과 확인 자료는 처리 종료 후 90일 이내 삭제합니다.

광고 서비스의 식별자·진단·상호작용 정보는 게임의 익명 랭킹 계정과 연결하여 보관하지 않습니다. 해당 정보의 삭제 요청은 이용자가 제공할 수 있는 식별 범위에서 서비스 제공자에게 전달하거나 제공자의 개인정보 관리 절차를 안내합니다. 제공자의 로그·백업은 해당 제공자의 보관·삭제 절차를 따르며 즉시 백업 제거를 보장하지 않습니다.
